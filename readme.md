# Project MME Collective

Projet de site web statique développé en HTML et CSS par Margaux, Mats et Ethan. L'objectif était de concevoir une plateforme vitrine présentant l'équipe, ses compétences ainsi que des pages personnelles pour chaque membre.

## Navigation du site

- index.html : Page d'accueil générale présentant l'équipe MME Collective, nos valeurs et nos domaines d'expertise.
- margaux.html : Page personnelle de Margaux (UI/UX Designer).
- mats.html : Page personnelle de Mats (Software Engineer).
- ethan.html (ou pje.html) : Page personnelle d'Ethan (Project Manager).

## Technologies utilisées

- HTML5
- CSS3 (Flexbox, CSS Grid, Scroll-snap pour la navigation sur la page d'accueil)
- JavaScript natif (gestion des onglets interactifs sur certaines pages)
- Polices d'écriture importées depuis Google Fonts (Poppins)

## Structure des dossiers

- / : Contient l'ensemble des fichiers HTML du projet.
- /src/style.css : Feuille de style principale regroupant l'ensemble de la charte graphique.
- /src/###.css : Feuille de style des pages personnelle de chacun.
- /public/ : Dossier regroupant les images, logos et illustrations de l'équipe.

## Note sur l'utilisation de l'IA

Les illustrations du site ainsi que la rédaction de ce fichier README ont été générées à l'aide d'outils d'intelligence artificielle. Le code HTML, CSS et JavaScript a quant à lui été structuré et ajusté sur mesure pour répondre aux besoins du projet.
